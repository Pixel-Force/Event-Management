# Event Management — Premier Celebrations, Weddings & Event Production Template

A clean, modern, ultra-responsive HTML5/CSS3/Vanilla JavaScript template crafted for luxury wedding coordinators, event planners, concert and festival promoters, and corporate summit organizers.

Re-architected from the ground up to deliver all the high-end design appeal and functional richness of premier celebrations platforms (inspired by Presentup), while completely removing all WordPress dependencies, database structures, plugins, PHP overhead, and branding.

---

## 🌟 Key Features & Capabilities

- **100% WordPress-Free Architecture:** Pure, semantic HTML5, modern CSS3 (custom CSS variables, flexbox, responsive grids), and vanilla JavaScript. Zero jQuery or framework overhead.
- **Clickable Header & Footer Brand Logos:** Vector brand mark ("Event Management") in both the elevated sticky header and the dark footer linking seamlessly to `index.html`.
- **15 Production-Ready Pages:**
  1. `index.html` — Flagship Celebrations Edition (Elevated Sticky Navbar, Hero Banner with Dual CTAs, Quick Inquiry Filter Bar, About Section with 15+ Years Badge, Stats Counter Bar, 6 Service Offerings, Filterable Upcoming Events with Ticket Booking Modal, 6-Category Photo Gallery with Lightbox, 4-Step Event Process, Client Feedback Testimonials, Latest Blog Insights, Pre-Footer CTA Bar, and 4-Column Footer with Clickable Logo).
  2. `homepage-2.html` — Festivals & Arenas Edition (High-energy hero, live event countdown clock, pass tiers & VIP ticket cards, stage schedule).
  3. `about-us.html` — About Us (Company story, founding vision, milestone timeline 2010–2026, core values, leadership team).
  4. `services.html` — Full Services Catalog (8 comprehensive event disciplines, 3-tier pricing comparison table: Silver, Gold, Platinum Packages).
  5. `service-details.html` — Service Deep Dive (Wedding Planning & Design, inclusion checklist, planning timeline, booking inquiry form, FAQs).
  6. `our-events.html` — Filterable Events Schedule (All, Celebrations, Festivals & Music, Corporate Summits, instant ticket modal).
  7. `event-details.html` — Event Detail View (Live countdown clock, run-of-show schedule itinerary, venue directions, ticket selection & booking).
  8. `our-team.html` — Event Production Team (Creative directors, lighting architects, floral designers, master sommeliers with bio cards & social links).
  9. `gallery.html` — Photo & Video Moments Gallery (Category filter tabs, responsive masonry grid, and interactive full-screen Lightbox viewer).
  10. `faq.html` — Categorized Knowledge Base (Accordion tabs for General Planning, Venues & Catering, Budget & Policies, live instant search).
  11. `blog.html` — Event Planning Journal (Article directory with featured photos, category badges, author tags, and sidebar widgets).
  12. `blog-details.html` — Full Article View (Typography, key takeaways callout, pro tips, author bio card, and comment submission form).
  13. `contact-us.html` — Contact & Studio Locations (Direct office cards, interactive lead inquiry form with instant validation, Google Maps embed placeholder).
  14. `privacy-policy.html` — Client Confidentiality & Data Protection Policy (Event non-disclosure agreements & privacy terms).
  15. `terms-and-conditions.html` — Terms of Service & Event Ticket Reservation Agreement.

- **Interactive Dynamic Functionality:**
  - Dynamic Ticket Calculator in booking modals with real-time price tally.
  - Live Event Countdown Timer ticking every second.
  - Full-screen image lightbox viewer for gallery photography.
  - Interactive accordion controls for FAQs and mobile navigation drawer.
  - Toast notifications confirming instant booking and message dispatch.
  - Mobile offcanvas navigation with accordion submenus.
  - Back-to-top smooth scrolling trigger.

## 🚀 Local Preview

You can open any `.html` file directly in any modern web browser or run via local HTTP server:

```powershell
# Option 1: Open directly
start index.html

# Option 2: Run with local HTTP server
npx.cmd serve .
# or
python -m http.server 8080
```
